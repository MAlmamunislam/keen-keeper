# 🤝 BondTracker - Personal Relationship CRM

**BondTracker** is a modern web application built with **Next.js** designed to help you maintain and nurture your friendships. In our busy lives, we often lose touch with people who matter. This app tracks your interactions and reminds you when it's time to reach out.

---

## ✨ Key Features

* **Dynamic Dashboard:** View all your friends and their current contact status at a glance.
* **Smart Status Indicators:** Automatically highlights friends as `On Track`, `Almost Due`, or `Overdue` based on your last interaction.
* **Category Tagging:** Organize friends into groups like `University`, `Coding Buddy`, or `School Friends`.
* **Dynamic Profiles:** Dedicated profile pages for every friend using Next.js Dynamic Routing.
* **Modern UI:** A clean, minimalist, and responsive design built with **Tailwind CSS** and **DaisyUI**.
* **Interactive Elements:** Smooth image hover animations and premium card layouts.

---

## 🛠️ Tech Stack

* **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) & [DaisyUI](https://daisyui.com/)
* **Language:** JavaScript (React)
* **State Management:** React Hooks (`useState`, `useEffect`)
* **Data Source:** Local JSON API
